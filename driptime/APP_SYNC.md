# 앱 반영 대기 목록

앞으로 웹에서 먼저 수정·확인하고, 앱은 마지막에 이 목록을 기준으로 반영합니다.

## 물 단위 표기 — 반영 대기

- 웹 반영: 2026-09-19
- 물 양 표시는 모두 `ml`로 통일합니다. 원두 양은 `g`로 유지합니다.
- 대상: 현재 누적 목표, 단계 누적 목표, 단계별 추가 물 양, 이전·다음 단계, 레시피 상세, 원두/물 요약, 한국어·영어 안내 문구.
- 수치와 타이머 계산은 유지합니다. 기존 JSON의 `waterGrams`, `startWaterGrams`, `endWaterGrams` 키는 호환성을 위해 유지하며 웹 표시에서는 같은 수치를 ml로 사용합니다.
- 앱은 아직 수정하지 않았습니다. 최종 반영 시 ContentView의 물 단위와 레시피 안내 문구 표시를 변경합니다.
- 확인 예: 원두 `20g` / 물 `300ml`, 누적 목표 `40ml / 150ml`, 이 단계에서 `+110ml`, 안내 문구 `160ml 드로다운 후 140ml 가수`.

## 현재 단계 레이아웃 — 반영 대기

- 웹 반영: 2026-09-19
- 원 안에는 현재 누적 물 양(ml)과 현재 단계 경과 시간만 표시합니다.
- 원 왼쪽: 단계명 최대 2줄, 이번 단계 추가 물 양, 완료 표시.
- 원 오른쪽: 이번 단계 목표 시간(단계 지속 시간), 목표 누적 물 양. 드로다운 수동 확인 단계는 목표 시간 대신 직접 확인으로 표시합니다.
- 현재 단계 문구와 위·아래 연한 구분선을 유지합니다.
- 앱은 최종 반영 때 변경합니다.

## 단계 제목의 물 양 제거 — 반영 대기

- 웹 반영: 2026-09-19
- 레시피 상세와 이전·다음 단계의 제목에서 자동으로 추가하던 +40ml 등의 물 양을 제거합니다.
- 물 양은 전용 목표 표시와 이번 단계 추가 물 양 표시에서 유지합니다.

## 뜸들이기 단계 구성 확인

- V60 기본 3-Pour: 0–30초에 0→40ml. 초기 물 붓기와 뜸 대기가 한 단계에 합쳐져 있습니다.
- James Hoffmann V60: 0–45초에 0→60ml. 초기 물 붓기와 뜸 대기가 한 단계에 합쳐져 있습니다.
- Coffee Collective 원푸어: 사전 적심 0–30초에 0→32ml. 초기 적심과 뜸 대기가 한 단계에 합쳐져 있습니다.
- Tetsu Kasuya 4:6 3종: 첫 물 붓기 구간 0–45초에 각각 60/70/50ml. 첫 붓기와 다음 붓기까지의 간격이 합쳐져 있습니다.
- 정인성 484/4666: 0–10초 사전 적심 40ml와 이후 물 양을 유지하는 뜸들이기가 이미 분리되어 있습니다.
- 합쳐진 단계에서는 현재 타이머가 구간 전체에 걸쳐 물 양을 선형으로 증가시키므로 대기 중에도 물 목표가 증가합니다.
- 초기 물 붓기 완료 시각은 공통 파일에 없으므로 이번 변경에서는 시간을 임의로 나누지 않았습니다. 추후 붓기 시간을 정한 뒤 물 붓기/대기를 분리해야 합니다.

## 레시피 원본 대조 및 물 붓기/대기 분리 — 반영 대기

- 웹 반영: 2026-09-19. 앱 코드·빌드는 수정하지 않음. 공통 recipes.json은 다음 앱 반영 때 함께 사용.
- 최초 붓기가 포함된 구간을 10초 사전 적심 + 남은 뜸 대기로 분리. 10초는 사용자 승인한 타이머용 권장값이며 원본 사실로 표시하지 않음.
- Hoffmann: 30g/500ml와 0:45·1:15·1:45·3:30은 원본과 일치. 수온은 가능한 뜨겁게(표시 기본 100°C), 초기 스월과 1:45 교반·스월 안내를 보완.
- Kasuya 3종: PHILOCOFFEA 제작자 가이드의 0:00·0:45·1:30·2:15·2:45, 3:30 종료로 통일. 기존 2:10·2:50 시작을 수정. 각 붓기를 권장 10초와 물 양 고정 대기로 분리. 수온은 해당 가이드의 약배전 93°C 기본, 중배전 88°C/강배전 83°C 안내. 60/60,70/50,50/70 변형 유지.
- Coffee Collective: 초기 32→30ml. 1:45는 250ml 물 붓기 완료이며 드로다운 대기를 추가. 공식 총 시간 범위 1:45–2:45 중 자동 안내 목표는 2:45로 표시(실제 완료 시각 보장 아님). 온도 범위 92–95°C, 표시 기본 94°C.
- V60 기본: 정확히 일치하는 원본 미확인. 개인 기본 레시피라고 안내하고 시간/수치 유지.
- 정인성 484/4666: 원본 영상 상세를 확보하지 못했으므로 원본 확인 완료라고 하지 않음. 기존 설정 유지, 상세 확인 대기를 안내.
- 각 레시피 sources/sourceStatus 및 timingBasis에 근거 기록. JSON 필드와 UUID 호환성 유지.

## 단계 카드·스크롤·원두 양 조절 — 반영 대기

- 웹 반영: 2026-09-19. 앱 코드와 빌드는 이번에 수정하지 않음.
- 레시피 선택 및 원두 양 조절을 상단에 배치. 원두 5–60g, 1g 단위. 시작 후 레시피·원두 양 잠금, 초기화 후 변경 가능.
- 기본 JSON은 보존하고 선택 원두 양 / 원본 원두 양으로 물 목표를 비례 조절. 누적 목표를 가장 가까운 5ml로 반올림, 단계 추가량은 누적 목표 차이. 대기 단계 물 양 고정 및 마지막 총량 일치. 시간·온도는 유지.
- 진행 중 물 목표는 1ml로 표시. 안내 문구 속 물 양도 비례 조절.
- 단계들을 세로 카드로 나열. 시작 후 현재 카드만 원형 타이머(누적 물 양·단계 경과 시간) 표시. 완료 단계 체크.
- 단계 전환 시 현재 카드로 부드럽게 이동. 사용자의 휠·터치 이동·스크롤 키 입력 시 자동 이동 중단. 현재 단계로 돌아가기 버튼으로 재개.
- 수동 확인 단계 안에만 다음 단계 버튼. 마지막 물 양 고정 단계는 런타임에 수동 드로다운 확인으로 설정, 추출 완료 버튼 제공. 원본 JSON 시간은 목표 참고값으로 유지. 가수로 끝나는 레시피는 기존대로 자동 완료.
- 시작/일시정지/초기화와 전체 진행률은 하단 고정. 타이머 수동 마지막 단계 확인 후 즉시 완료 처리를 앱에도 반영 필요.

- 추가 결정: 레시피 선택, 시작·일시정지, 초기화, 필요한 단계의 다음/완료 버튼은 화면 상단에 고정. 수동 버튼은 현재 단계에서만 표시하며 단계 카드에는 안내만 표시. 상단 영역 높이에 맞춰 자동 스크롤 여백 조절.
